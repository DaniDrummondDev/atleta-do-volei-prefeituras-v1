# Alterações de conteúdo para aprovação do cliente

Este documento não foi aplicado à LP. Ele reúne somente recomendações que alteram texto visível, hierarquia de headings, seções ou posicionamento comercial. As correções técnicas já aplicadas não mudam o conteúdo nem o layout da página.

## Decisão de posicionamento

**Situação atual:** a página se apresenta principalmente para atletas, mas algumas seções falam em cidade, gestão esportiva, escolas e anúncios.

**Aprovação necessária:** definir se esta URL continua exclusivamente para o aplicativo de atletas (B2C) ou se também vende uma solução para prefeituras/instituições (B2B). Se houver produto institucional, a recomendação é criar uma página própria, com proposta, recursos, provas e CTA próprios.

## Blocos de conteúdo candidatos

1. **O que é o Atleta do Vôlei?** Logo após o hero, incluir uma definição curta do aplicativo, público e principais ações. Ajuda visitantes, Google e mecanismos de resposta a compreenderem a página sem depender da navegação visual.
2. **Métricas com contexto.** Se os números de atletas, equipes e eventos continuarem na LP, acrescentar fonte e mês/ano da atualização. Caso não haja fonte, aprovar a remoção dos números.
3. **Informações institucionais e confiança.** Criar ou vincular páginas de suporte, privacidade/localização, regras de comunidade e critérios de cadastro/avaliação de quadras, somente conforme a operação real.
4. **Premium.** A página pública atual menciona Premium, mas a nova LP não. Confirmar se o produto existe e se deve receber uma seção/FAQ visível antes de citá-lo em qualquer metadado ou Schema.

## FAQ candidata

Para ampliar respostas úteis sem criar perguntas artificiais, aprovar apenas perguntas que o produto possa comprovar:

- O que é o Atleta do Vôlei?
- O Atleta do Vôlei é gratuito para baixar?
- Quem pode usar o aplicativo?
- Como encontro jogos, equipes, atletas e quadras?
- Posso criar uma equipe ou participar de uma existente?
- Posso criar torneios e amistosos pelo aplicativo?
- Como cadastrar uma quadra ou local para jogar?
- O app está disponível para Android e iPhone?
- Como entrar em contato ou reportar um problema?

## Evidências e promessas que exigem validação

Antes de usar ou ampliar estas afirmações em textos visíveis, confirmar responsável, fonte e data: atletas ativos, equipes, eventos organizados, filtros por nível/localização/piso, avaliação de quadras, dados para decisões, chat, placar eletrônico, board tático, escolas, anúncios e qualquer oferta Premium.
